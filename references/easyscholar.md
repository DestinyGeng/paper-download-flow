# easyScholar 插件分析（v15.7）

> 目的：判断它能不能当"1区2区"的**判据来源**，以及徽章怎么读。

## 1. 它是什么

Chrome 扩展（id `njgedjcccpcfmjecccaajkjiphpddfji`），在 WoS、Google Scholar、PubMed 等页面上叠加期刊等级徽章。

**本地只有 `storage` 权限，没有任何排序/判定代码**——所有等级都来自服务端（`www.easyscholar.cc`）。
所以"评判标准"不是插件定的，是它**订阅的那 100+ 个数据集**定的。换数据集 = 换判据。

## 2. 数据集分类（官方文档口径）

| 类别 | 数据集 | 等级 |
|---|---|---|
| **国际分区** | SCI/SSCI（JCR）、中科院基础版、中科院升级版、中科院 TOP、新锐分区 | Q1–Q4 / 1–4区 / Top |
| **指标** | 影响因子 IF、5 年 IF、JCI、ESI 学科分类 | 数值分档（IF：10/4/2/1/0；JCI：3/1/0.5/0） |
| **索引** | EI、A&HCI、北大核心、CSSCI（含扩展版）、CSCD、中国科技核心 | 收录/不收录 |
| **学会分级** | CCF（A/B/C，=T1/T2/T3）、FMS（A/B/C/D） | 学科内分级 |
| **商学院** | ABS/AJG（4*/4/3/2/1）、FT50、UTD24 | 名单制 |
| **预警** | 中科院预警名单、新锐预警 | **黑名单** |
| **高校自定** | 西财、中央财大、复旦、上交、厦大、人大、对外经贸、西南交大、西电、河海、地大、川大、重大、浙大、南大、新疆大学、长大等 | 各校自定 A/B/C… |

**关键发现：内置数据集里没有"中南财经政法大学"。** 你校若有校定期刊目录，需要自己做成"自定义数据集"导入，否则插件里看到的 1 区 2 区都是中科院/JCR 口径，不是校定口径。

## 3. 徽章怎么读（用你截图里的三篇举例）

| 徽章 | 含义 | 来源 |
|---|---|---|
| `JCI 1.49` | 期刊引文指标，1.0 = 全球平均 | Clarivate JCR |
| `IF(5) 9.0` | 5 年影响因子（比 2 年更稳） | JCR |
| `SCI升级版 计算机科学1区` | 中科院升级版，按"期刊超越指数"，18 个大类 | 中科院文献情报中心 |
| `SCI基础版 工程技术2区` | 中科院老版，13 个大类，3 年平均 IF | 同上 |
| `SCI Q1` / `SSCI Q2` | JCR 学科内四分位 | Clarivate |
| `计算机科学TOP` / `经济学TOP` | 中科院大类 Top（"又大又强"） | 中科院 |
| `CCF C` | 中国计算机学会推荐等级 | CCF |
| `FMS C` | 管理科学高质量期刊（A/B/C/D） | FMS |
| `AJG 1` / `ABS 3` | 英国商学院协会期刊指南 | ABS |
| `ESI学科分类：工程科学` | ESI 22 个领域归属 | Clarivate |
| `UIBE B` / `SWJTU A++` / `SDUFE A2` / `HHU A类` / `CUG 工程技术T2` / `XJU 一区` / `SCU … C` / `SWUFE B` / `RU C B` | 各高校自定目录 | 各校文件 |

三篇的对照很说明问题：

| 论文 | 期刊 | JCR | 中科院 | 学会/商学院 |
|---|---|---|---|---|
| A hierarchical DL framework for pair trading | Expert Systems with Applications | SCI Q1 | 计算机科学 **1 区** + TOP | CCF C、FMS C |
| Signature Decomposition… | Journal of Futures Markets | SSCI Q2 | 经济学 **4 区** | AJG 3、FMS B |
| Pair trading with high-frequency data… | China Finance Review International | SCI Q1 | 经济学 **1 区** + TOP | — |

**同一本刊在不同体系里等级可以差很多**（JCR Q1 但中科院 4 区，或反之）。所以"1区2区"必须先指定体系，否则规则无法执行。

## 4. 对我们的筛选（SKILL.md 3.2 闸 B）怎么用

建议**三层判据**，优先级从高到低：

1. **中科院升级版 1/2 区 + TOP 标记**（国内主流口径，也是你截图里最显眼的徽章）
2. **JCR Q1/Q2**（国际通行，做交叉验证）
3. **学科补充**：计算机看 CCF ≥ B；金融/管理看 ABS ≥ 3 或 FT50/UTD24

**一票否决**：中科院预警名单 / 新锐预警 → 直接拒，不看分区和引用。

## 5. 自动化可行性

- 插件数据是服务端返回，没有公开 API 文档 → **不适合直接抓**；
- 自动化判定建议：OpenAlex（被引、百分位）+ SJR（开放分区 CSV）；
- easyScholar 用在**人工复核层**：决赛名单 20 篇，你在 WoS 页面上一眼扫徽章，比任何脚本都快；
- 若要自动化到"中科院分区"，需要你每年把分区表 Excel 给我，做成本地查询表。

## 6. 结论

- 它能当**复核工具**，不能当**自动判定源**；
- 它的价值在于把多个体系并排显示，让你一眼看出"这篇在中科院是几区、JCR 是 Q 几、商学院算不算好刊"；
- 真正决定选文的，是我们自己写死的规则（3.2 三道闸）+ 你确认的体系口径。
